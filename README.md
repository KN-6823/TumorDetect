# 🧠 Brain Tumor Detection using MRI and CNN

This is a web-based AI tool for detecting the **presence of brain tumors** using **MRI images**. Built with Convolutional Neural Networks (CNNs), it helps provide quick, consistent results to assist in early diagnosis.

---

## 🚀 Features

- 📷 Accepts MRI images only
- ✅ Predicts: **Tumor Detected** / **No Tumor**
- 🖥️ Simple web interface for image upload
- 📊 Console displays probability and model metrics (Accuracy, Precision, Recall)
